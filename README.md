# 15퍼즐 🧩

빈칸을 이용해 타일을 밀어 1부터 차례로 맞추는 슬라이딩 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- **3×3(쉬움) · 4×4(보통) · 5×5(어려움)**. 1부터 차례로 왼쪽 위 → 오른쪽 아래, 마지막이 빈칸이 되면 완성
- 빈칸과 **같은 줄(가로·세로)**에 있는 타일을 누르면 그 사이 타일들이 빈칸 쪽으로 한 번에 밀린다. 이동 수는 타일이 한 칸 움직일 때마다 센다(두 장을 밀면 2). PC는 방향키로도 민다
- 타일 색은 목표 줄마다 다르다(위 줄부터 맞춰 가기 쉽다). 제자리에 맞은 타일은 테두리가 밝아진다. 시간은 첫 번째로 민 순간부터 흐른다
- **풀 수 있는 판만 나온다**: 뒤집힌 쌍의 수와 빈칸 줄로 판정한다. 3×3 의 도달 가능한 배치 181,440개와 판정이 완전히 일치하는 것을 시험으로 확인했다
- 💡 힌트: 3×3 은 정확한 최단 풀이(IDA*)의 다음 수, 4×4·5×5 는 빠른 근사 풀이(가중 A*)의 다음 수. 한 번에 -40점. 3×3 은 끝나면 '최적 풀이 대비 몇 수 더 썼는지'를 보여 준다
- ↩️ 되돌리기(되돌리기도 한 번으로 침) · 이어하기(자동 저장) · 일시정지
- 점수 = 크기별 기본 점수(400/1,500/4,000) − 이동·시간·힌트 감점(최소 50). 크기별 최고 점수·최소 이동·최단 시간을 저장(`puzzle15Best{3,4,5}` · `puzzle15BestMoves{n}` · `puzzle15BestTime{n}`), 로비 표시용은 가장 큰 점수 `puzzle15Best`
- PC: 방향키 이동 · Z 되돌리기 · H 힌트 · M 소리 · P 일시정지

규칙·풀이는 `logic.js`(화면 없이 Node 로 시험할 수 있다: `node test/logic.test.js`), 화면·입력은 `game.js`.
